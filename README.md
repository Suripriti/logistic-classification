# Titanic Survival Prediction

This project predicts whether a Titanic passenger survived or not using Logistic Regression and Streamlit.

## Technologies Used
- Python
- Streamlit
- Pandas
- Scikit-learn

## Machine Learning Algorithm
- Logistic Regression

## Dataset
Titanic Dataset from Kaggle

## Run Project

pip install streamlit pandas scikit-learn

streamlit run app.py
